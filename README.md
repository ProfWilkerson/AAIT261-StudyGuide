# AAIT261 Study Guide
## AWS Certified AI Practitioner (AIF-C01)

Welcome to the AAIT261 study guide. This resource supports your preparation for the AWS Certified AI Practitioner certification exam and is organized to follow the course module structure.

Each module's study guide covers the relevant certification domain task statements, key vocabulary, concept breakdowns, and scenario-based practice questions in the format of the actual exam.

---

### How to Use This Guide

Use the sidebar to navigate by module. Each module page includes:

- **Key Terms** — vocabulary and definitions mapped to certification domain objectives
- **Concept Breakdowns** — tables and explanations to help you understand relationships between ideas
- **Practice Questions** — scenario-based questions written in the style of the AIF-C01 exam, with answers and explanations

This guide is a supplement to AWS Academy and course materials, not a replacement for them. The AWS Academy student guides, activities, and knowledge checks are your primary learning resources.

| Item | Detail |
